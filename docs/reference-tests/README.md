# Справочные сценарии прежнего интерфейса

Файлы `*.ts.txt` сохранены для будущего повторного использования сценариев. Они не входят в Vitest, Playwright и TypeScript-проверку и не считаются проходящими тестами.

- `e2e-*` — согласие на аналитику, тема, старая навигация, CMS и отзывы. Компоненты ещё не подключены к текущим страницам. При возврате обновить селекторы, тексты и ID аналитики (`sweet-lana-*`).
- `unit-testimonials*` — проверки конкретных отзывов прежнего бизнеса. Данные переносить нельзя. Вместо них работают тест пустых манифестов и преобразование синтетических отзывов.
- `unit-review-image-preparation*` — пример проверки обезличивания изображений. Скрипт `scripts/prepare-review-images.mjs` отсутствовал уже в исходном Sweet-lana. Для возвращения сценария сначала потребуется сам инструмент.

Общие проверки auth, Telegram, MongoDB, оптимизации R2 и аналитики не архивированы: они запускаются через `npm run test:reusable` и CI. Актуальные браузерные сценарии: `tests/e2e/site.spec.ts`.
